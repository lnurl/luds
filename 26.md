LUD-26: `POST` callbacks.
=========================

`author: dni` `status: draft`

---

Any `callback` defined in any LUD MAY also be called with an HTTP `POST` request instead of `GET`.

Instead of appending parameters as URL query parameters, `WALLET` sends the exact same parameters as a JSON object in the request body with `Content-Type: application/json`.

Example, instead of:

```
GET <callback>?k1=<k1>&pr=<invoice>
```

`WALLET` sends:

```
POST <callback>
Content-Type: application/json

{"k1": "<k1>", "pr": "<invoice>"}
```

Any query parameters already present in the `callback` URL MUST be kept as they are.

The response is identical to the `GET` version. `LN SERVICE` that does not support this LUD will respond with an error, in which case `WALLET` SHOULD fall back to `GET`.
